# Lucero

Lucero 是一个 Windows Local-First 多 AI Agent 控制平面。

## Qoder 开工顺序

1. 先读 `README_QODER_START_HERE.md`
2. 再读 `docs/architecture/SYSTEM_ARCHITECTURE_V0.1.md`
3. 再读 `docs/architecture/CORE_DOMAIN_MODEL_V0.1.md`
4. 执行 `docs/adapters/PHASE0_ADAPTER_CAPABILITY_SURVEY.md`
5. 按 `docs/planning/QODER_FIRST_SPRINT.md` 开始 FakeAdapter Sprint

核心技术栈：Tauri 2 + Vue 3 + TypeScript + Go + SQLite。
